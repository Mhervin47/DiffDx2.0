# Task specs

Working specifications written during the v2 rebuild, in execution order.
Each was handed to an agentic coding session as the unit of work, with
acceptance criteria checked before the branch merged. Kept in the repo as a
record of how the project was built.

Roughly, in order: `TASK2` (repository layer) through `TASK27` (email OTP
verification) — spanning the blob-store → relational cutover, JWT auth,
Redis session persistence, Docker/Compose, and the documentation pass this
README is part of.
